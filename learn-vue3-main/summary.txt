▶ Vue 실행방법 (Vite)
- Vite (비트) ?
  : Vue SFC를 지원하고 매우 가볍고 빠른 빌드 도구
  : Vue!의 저자이기도 한 Evan You가 제작

- Vite 사용 이유?
  : 개발 서버를 구동할 때 매우 빠름
  : 소스 코드의 변경이 일어났을 때 전체 모듈을 번들링 하는게 아니라,
   변경된 모듈만 교체하기 때문에 개발을 더욱더 빠르게 진행할 수 있음

- 실행
  > 프로젝트에서 터미널을 연 후 아래 명령어 입력
	npm init vue@latest
	y

  > 아래 명령어 추가 입력
	cd {product name} << 생략해도 진행가능 한디...?
	npm install
	npm run dev
    : 이 명령은 공식 Vue 프로젝트 스캐폴딩 도구(create-vue) 를 설치하고 실행함

  > http://localhost:3000/
