▶ vue 설치방법 (vue.CLI)

1. 터미널에서 node.js 버전 확인 (설치여부 확인)
    node -v

2. npm 버전 확인
    npm -v

3. vue.CLI install
    npm install -g @vue/cli

4. vue.CLI 설치확인
    vue -V

5. 프로젝트 생성을 위한 경로로 이등
    cd D:\Study\Vue

6. 프로젝트 생성
    vue create vue3-project
    - vue3 선택
    - 생성 중엔 다른 거 열지 말자...첨부터 다시 맹그럿슴

7. 익스텐션 설치
    - vetur (pine Wu 제작)
    - vetur 웹사이트에서 project 셋업하는 방법 따라 작업해주기
        > https://vuejs.github.io/vetur/guide/setup.html#vs-code-config
        > jsconfig.json에 내용 추가
            {
                "include": [
                "./src/**/*"
                ]
            }

8. npm run serve

▶ js 객체 복사/비교
- 원시 타입
- 참조 타입 (주소값에 주목)
    - a = {a: 1 ,b: 1} , b = a 일 때, a === b --> true
    - b.a = 3 일 때 a.a = 3
    - a에 영향을 주지 않고 사용/변경 하고자 할 경우, 새로운 변수에 새 객체 생성
        > c = {...a} 일 때,
          1) a === c --> false
          2) a.a === c.a --> true
             JSON.stringify(a) === JSON.stringify(c) --> true
          3) d = {b: 1, a: 1}
             JSON.stringify(a) === JSON.stringify(d) --> false
             (단, 객체 내 데이터의 순서가 다르면 false)
          3) lodash 라이브러리 사용
             _.isEqual(a, d) ---> true

- lodash 라이브러리 설치
    npm i lodash
